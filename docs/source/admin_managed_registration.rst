Admin-managed registration
==========================

This page is now :doc:`invitations`, which covers the same flow — an admin creates the
account and the invitee sets their own password — under the name people look for.

``JWT_ALLAUTH_ADMIN_MANAGED_REGISTRATION`` is unchanged and still documented there,
alongside ``JWT_ALLAUTH_INVITATIONS``, which adds invitations without closing
self-service registration.
